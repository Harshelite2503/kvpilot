# Preliminary development smoke run

This two-case, one-repetition roomy-store run verified the new integration before
the full experiment. All responses, timings and failures remain here. These
observations are excluded from the formal result totals and are not independent
holdout evidence.

The harness subsequently gained startup source/fixture freeze checks, a copied
fixture artifact, stricter bytewise integrity wording, argument checks and the
`adaptive_exact` comparison arm. Consequently, the current source hashes do not
match this earlier development protocol. Use [the complete formal archive](../qwen-kvpilot-v1/)
and [reproduction guide](../../docs/local-runner.md) for the current experiment.
